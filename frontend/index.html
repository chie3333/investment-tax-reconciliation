같은 종목도 FVOCI와 FVTPL은 서로 다른 asset_id로 관리합니다. 동일 종목·동일 분류의 반복 매수는 기존 asset_id에 연결됩니다.

거래 입력

종목코드를 입력하면 마스터에서 조회합니다.

매수금액은 수량 × 단가로 계산합니다.

거래 입력 안내

종목코드로 종목명·시장구분을 자동 조회합니다. 매도·배당은 기존 투자자산 중 처리 대상을 선택합니다.

회계상 원가배분은 총평균·이동평균·선입선출·개별법 중 선택(기본 총평균), 세법상은 총평균법(기본) 또는 이동평균법(신고 시)을 선택합니다. 연도 중 총평균 금액은 이후 취득으로 변경될 수 있습니다. 매도 후 음수 보유수량이 발생하지 않도록 검사합니다.

세무조정 내역 · 유보 변동

종목별 통합 세무원가 대사

회계분류별 세무장부금액은 동일 종목의 총 세무원가를 잔여 수량 비율로 배분한 표시금액입니다. 과거 거래별 원장과 FVOCI 기타/유보 대응은 별도 검토가 필요합니다.

회계·세무 금액 비교

회계 장부금액과 세법상 장부금액은 거래·평가 이벤트를 시간순으로 재계산합니다. 세무조정은 규칙 적용 가능한 범위에서 자동 생성합니다. 신고용 결과가 아니며 법인별 예외 검토가 필요합니다.

회계 · 법인세 자동 계산 엔진

일반 내국법인 · 국내 상장 보통주 · K-IFRS 1109 · 한국 법인세법을 대상으로 하는 검증용 자동 계산입니다. 거래별 회계 장부금액, 세무상 원가, 평가손익, 처분손익, 자동 세무조정과 유보를 재계산합니다.

법인별 세법상 평가방법 신고·변경 관리

투자목적·매매목적 또는 FVOCI·FVTPL 분류만으로 세법상 원가계산 방법을 나누지 않습니다. 신고 사실이 불명확한 경우 계산은 검토용이며 신고 적합성을 확정하지 않습니다.

연도별 정책 이력

적용 시작연도 이후 다음 변경연도 전까지 해당 방법을 사용합니다. 현재 엔진은 1월~12월 사업연도 가정이며, 신고기한·효력 자동 법률판정은 제공하지 않습니다.

종목을 선택해 원가계산 정책을 확인하세요.

회계상 원가배분 방법은 종목별 시뮬레이션 정책으로 관리합니다. 세법상 방법은 법인별 신고 정책으로 관리하고 동일 종목의 원가를 종목별로 계산합니다. 투자목적·매매목적 또는 FVOCI·FVTPL이라는 이유만으로 세법상 원가계산 방법을 나누지 않습니다. 첫 거래 저장 후 정책은 잠겨 기존 거래와 향후 거래에 동일하게 유지됩니다. 초기 선택값만 총평균법입니다. 개별법은 매도 시 취득 LOT를 지정해야 합니다. 회계정책의 실제 적합성은 별도 검토가 필요합니다. 세법상은 총평균법 또는 이동평균법을 선택합니다. 총평균법을 모델 가정으로 적용하며, K-IFRS가 이를 유일한 기본방법으로 지정한 것은 아닙니다. 세법상 원가 계산방법은 별도로 선택합니다. 총평균법의 연중 매도원가는 사업연도 후속 매수를 포함하므로 연말 확정 전에는 잠정치입니다. 동일 일자의 입력 순서는 매수·매도 후 평가로 가정합니다. 배당 익금불산입은 별도 요건 확인 전까지 자동 적용하지 않습니다.

국내 수입배당금 익금불산입 시뮬레이터

법인세법 제18조의2 기준의 조건부 계산입니다. 3개월 계속보유·배제 요건을 검토한 경우에만 계산하며, 차입금 이자 관련 차감액은 사용자가 산출하여 입력합니다. 자동 원장에 반영하지 않습니다.

규칙 및 미지원 범위

지원: 매수·매도·배당, FVTPL/FVOCI 공정가치 평가, 회계 원가배분 4가지 선택 및 세법 총평균/이동평균 선택, 장부가/세무가 차이, FVTPL 평가손익 세무조정, 처분 시 세무상 손익과 회계상 손익 차이, 유보 변동 계산.
제한: 총평균법의 연중 잠정치 및 회계정책 검토, 손상·재분류·주식분할, 외화, 수수료·증권거래세, FVOCI 처분 시 OCI의 자본 내 대체, 이연법인세, 법인별 세법 예외, 배당 익금불산입의 3개월 보유·차입금 이자 차감·배제 요건, 신고서 생성. FVOCI 평가 관련 세무조정은 당기손익 조정과 구별하여 별도 차이로 표시합니다.

결산 자동 검증

수량·평가 누락·장부금액 대사·유보 이월·신고 정책을 확인합니다. 검증 실행 결과는 SQLite에 이력으로 남습니다. 자동 검증은 법적 적합성 판단을 대신하지 않습니다.

유보 보조원장 · 사업연도 결산 확정

유보는 승인된 검증표에서만 발생하며 승인 취소 시 역분개로 상쇄합니다. 자동 계산은 승인 없이 원장에 반영되지 않습니다. 원장 부호: 유보 + / △유보 −.

수동 유보 입력은 비활성화되었습니다. 검증표 승인·취소에 의해서만 원장이 변동합니다.
